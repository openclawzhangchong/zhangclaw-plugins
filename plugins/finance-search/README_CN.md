# 财经资讯搜索（finance-search）

[English](./README.md)

中文财经资讯搜索 MCP 服务（东方财富公开搜索），返回标题、摘要、时间、媒体与原文链接，免账号。

## 使用

1. 在插件管理器中安装并启用「财经资讯搜索」。
2. 在会话中确认下列 MCP 工具已加载，然后用自然语言提出查询。例如：

> 搜一下最近关于「茅台 回购」的财经资讯，列出标题、时间和链接。

Agent 应从当前会话发现的工具中选择对应服务，按工具 schema 传参，不猜测工具名。服务命名空间为 `plugin:finance-search:finance-news`。本插件没有斜杠命令。

## MCP 工具

| 工具 | 返回 |
| --- | --- |
| `search_news` | 标题、摘要（截断 240 字）、发布时间、媒体名、原文链接 |

## 数据来源与边界

- 数据来自公开搜索接口 `so.eastmoney.com`，非官方授权数据源，可能限流或调整返回结构。
- 接口是 jsonp 包裹，代码按 `(...)` 解包；解不开时如实报错而不是返回空结果。
- 上游同名版本需要 Z.ai 账号鉴权；本版本免账号、免套餐。
- 版本 0.2.0 起为本实现。财经资讯搜索 的显示名已按实际数据源命名。

## 运行前提

服务是零依赖的 Node ESM 脚本（`mcp/server.mjs`），只用全局 `fetch`，插件包不含 `node_modules`；要求 `node` 在 PATH 上（与本仓库 `mimosa` 插件同一前置条件）。配置以 [`.mcp.json`](./.mcp.json) 为准，ZCode 自动发现插件根目录下的此文件。
