# 上市公司公告检索（tianyancha）

[English](./README.md)

沪深北上市公司公告检索 MCP 服务（巨潮资讯，交易所指定披露平台），免账号。

## 使用

1. 在插件管理器中安装并启用「上市公司公告检索」。
2. 在会话中确认下列 MCP 工具已加载，然后用自然语言提出查询。例如：

> 查贵州茅台（600519）最近披露的定期报告公告，给我标题和 PDF 链接。

Agent 应从当前会话发现的工具中选择对应服务，按工具 schema 传参，不猜测工具名。服务命名空间为 `plugin:tianyancha:announcements`。本插件没有斜杠命令。

## MCP 工具

| 工具 | 返回 |
| --- | --- |
| `search_announcements` | 公告标题、公司、代码、发布日期、PDF 直链 |

## 数据来源与边界

- **只提供交易所公告检索**，不含工商登记、股权穿透、司法风险等数据——因此不再使用「天眼查」作为显示名（slug 保留以兼容已有安装）。
- 按公司过滤必须走 `hisAnnouncement/query` 并先解析 orgId；实测 `fulltextSearch` 会静默忽略 `stock` 参数并返回无关公司的公告，代码里已按此实现。
- 上游同名版本需要 Z.ai 账号鉴权；本版本免账号、免套餐。
- 版本 0.2.0 起为本实现。上市公司公告检索 的显示名已按实际数据源命名。

## 运行前提

服务是零依赖的 Node ESM 脚本（`mcp/server.mjs`），只用全局 `fetch`，插件包不含 `node_modules`；要求 `node` 在 PATH 上（与本仓库 `mimosa` 插件同一前置条件）。配置以 [`.mcp.json`](./.mcp.json) 为准，ZCode 自动发现插件根目录下的此文件。
