# 市场数据（指数·K线·榜单）（wind）

[English](./README.md)

指数快照、日 K 线与市场榜单 MCP 服务，直连公开接口，免账号。

## 使用

1. 在插件管理器中安装并启用「市场数据（指数·K线·榜单）」。
2. 在会话中确认下列 MCP 工具已加载，然后用自然语言提出查询。例如：

> 取沪深300（sh000300）与贵州茅台的最新快照，再给我茅台最近 20 个交易日的日 K 线。

Agent 应从当前会话发现的工具中选择对应服务，按工具 schema 传参，不猜测工具名。服务命名空间为 `plugin:wind:market-data`。本插件没有斜杠命令。

## MCP 工具

| 工具 | 返回 |
| --- | --- |
| `index_snapshot` | 指数/个股现价、昨收、开高低、涨跌、涨跌幅 |
| `daily_kline` | 日 OHLCV 序列（默认前复权，1-250 个交易日） |
| `market_ranking` | 沪深主板/创业板/科创板按涨跌幅榜 |

## 数据来源与边界

- 数据来自公开接口 `push2.eastmoney.com` / `push2his.eastmoney.com`，**不是万得 Wind 官方数据**。
- 指数与个股会撞码：裸 6 位数字按股票推断，指数必须带前缀（`sh000300`、`sz399006`）。
- 上游同名版本需要 Z.ai 账号鉴权；本版本免账号、免套餐。
- 版本 0.2.0 起为本实现。市场数据（指数·K线·榜单） 的显示名已按实际数据源命名。

## 运行前提

服务是零依赖的 Node ESM 脚本（`mcp/server.mjs`），只用全局 `fetch`，插件包不含 `node_modules`；要求 `node` 在 PATH 上（与本仓库 `mimosa` 插件同一前置条件）。配置以 [`.mcp.json`](./.mcp.json) 为准，ZCode 自动发现插件根目录下的此文件。
